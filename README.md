# File-checking
โปรเจคนี้เป็นการทดสอบสร้างระบบตรวจการเปลี่ยนของไฟล์ทั้งหมดด้วยภาษา python ตามที่กำหนดในที่ในกำหนดเป็นทั้งหมดใน C:\ ด้วยจะมี func ให้ใช้อยู่ 4 อันคือ
1 func สร้าง table เพื่อใช้เก็บข้อมูล path และ hash ของไฟล์
2 แสดงข้อมูลทั้งหมดใน database
3 อัพเดทข้อมูลใน database โดยระบบคือการลบ table เป็นเก่าทิ่งและทำการสร้างใหม่เพื่อ reset data
4 คือการเตรียมจับมา file มีการเปลี่ยนแปลงมั้ยโดยจะทำการดึงข้อมูล path และ hash เก่าออกมาและจะทำการใช้ path ที่ดึงออกมาหาไฟล์ปัจจุบันแล้วเอามา hash แล้วก็เทียบกันว่าตรงมั้ยถ้าไม่ตรงจะทำการ detect
*หากโปรเจคมีข้อผิดพลาดหรือ error ตรงขออภัยนะที่นี้
